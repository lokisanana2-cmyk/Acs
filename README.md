# ACS Body Tempering x20

Mod for Amazing Cultivation Simulator.

## Feature
Increase **Body Tempering speed ×20**.

## Install
1. Download this repository or ZIP.
2. Copy the folder into the game's Mods directory.
3. Enable the mod in the Mod Manager.

## Structure
acs_body_temper_x20
 ├ Info.json
 ├ Scripts/
 │   └ BodyTemperX20.lua
 └ Settings/
     └ Body/
         └ BodyTemperModifier.xml
